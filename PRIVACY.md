# Privacy Policy

Effective: September 2, 2026

nulnul harness is a skills-only plugin. It has no publisher-operated server, account system, analytics, advertising, or telemetry, and the publisher does not collect, receive, sell, or retain personal data through the plugin.

The plugin gives instructions to the host agent. With the user's authorization, that agent may read or change files in the current project, discover available third-party capabilities, and use tools the user selects. nulnul harness does not transmit project files or discovery results to the publisher. It does not ask users to place passwords, API keys, tokens, raw conversations, or personal data in project guidance.

Project Memory, Sessions, Experiences, and raw transcripts remain project-local. Raw transcripts are local-only execution evidence and are excluded from durable Memory and evolution queries. Cross-project Generalization does not share project Memory: it accepts only privacy-classified abstractions with hashed source identity, applicability limits, and provenance. Unknown privacy status, source paths, source bodies, credentials, and private project Decisions fail closed. A target project must validate a transferable prior before it becomes target-project truth.

External capability discovery sends only a bounded sanitized job description to an explicitly configured source. Discovered bodies remain untrusted and quarantined, are not executed during discovery, and do not enter ordinary project context unless project verification and the lifecycle transaction accept them.

OpenAI and any user-selected tools or services process data under their own terms and privacy policies. Users control nulnul harness data by reviewing or deleting generated project-local files and by disabling or uninstalling the plugin.

For privacy questions, use the support channel listed in [SUPPORT.md](SUPPORT.md). For a security issue, follow [SECURITY.md](SECURITY.md).
