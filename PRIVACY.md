# Privacy Policy

Effective: August 4, 2026

Project Harness is a skills-only plugin. It has no publisher-operated server, account system, analytics, advertising, or telemetry, and the publisher does not collect, receive, sell, or retain personal data through the plugin.

The plugin gives instructions to the host agent. With the user's authorization, that agent may read or change files in the user's current project and may use tools already available in the user's environment. Project Harness does not transmit those files to the publisher. It does not ask users to place passwords, API keys, tokens, raw conversations, or personal data in project guidance.

OpenAI and any user-selected tools or services process data under their own terms and privacy policies. Users control Project Harness data by reviewing or deleting generated project-local files and by disabling or uninstalling the plugin.

For privacy questions, use the support channel listed in [SUPPORT.md](SUPPORT.md).
