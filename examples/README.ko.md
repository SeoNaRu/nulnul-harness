## 바로 사용해 보기

저장소 루트에서 Python 3.9 이상으로 실행합니다.

```bash
python3 examples/booking-service/app.py
```

`http://127.0.0.1:8765`를 여세요. 데모 시간을 고르고 가상의 이름으로 예약합니다. 새로고침하면 해당 시간이 예약 불가로 표시됩니다. 서버를 종료하면 메모리의 예약이 사라집니다. 데모 화면은 영어입니다.

포함된 HTTP 검사는 서버 실행과 별개입니다.

```bash
python3 examples/booking-service/app.py --check
```

HTTP 검사는 2026-09-09에 Python 3.12.3으로 통과했습니다. 이 명령 자체가 브라우저를 자동 조작하거나 하네스 효과를 측정하지는 않습니다. 별도의 Chromium 실행에서 오래된 탭의 예약 충돌, 모바일 배치, 키보드 예약, 안전한 텍스트 표시 등을 포함한 브라우저 검사 9개가 통과했습니다.

[로컬 검증 기록](validation-2026-09-09.json)에 소스 해시, 관련 단위 테스트 14개 통과, 과거 도입 증거 검증, 문서 검사 결과를 남겼습니다. 파비콘 누락으로 동작을 막지 않는 `404`가 발생했으며 수정하지 않았습니다. 이 결과는 검사한 예제 동작의 근거이지, 새로운 실제 도입이나 A/B 성능 우위의 근거는 아닙니다.

공개 전 검사에서도 변경하지 않은 3.1.0 플러그인을 기준으로 **저장소 테스트 447개 전체 통과**, **문서 부채 0건**, **Release Gate 100/100**을 확인했습니다. 예약 HTTP 검사는 이제 CI에 포함됩니다. 이번 공개 작업의 **새 Claude 및 다른 모델 호출은 0회**이며, 실행하지 않은 모델 비교 초안은 제외합니다.

## 모든 사례에서 밝히는 내용

- 원래 작업과 결과물, 그리고 기록된 결과·기대 결과·미검증 상태의 구분.
- 실제 재사용한 기능, 추가를 제안하는 기능, 활성화하지 않은 기능.
- 입력, 소스 또는 버전 참조, 재현 가능한 경우의 정확한 로컬 명령.
- 완료 조건과 하나 이상의 실패 조건 또는 음성 대조군.
- 측정한 비용·시간. 적격 측정이 없으면 `unknown`으로 표시.
- 자격 증명, 외부 쓰기, 유료 모델 호출 여부를 포함한 권한과 한계.

참조 앱을 하네스가 생성한 성공 사례로, 합성 프로젝트를 고객 운영 사례로, 준비 상태를 미래 세션의 실제 실행으로 바꾸어 소개하지 않습니다. 성공 기록과 함께 실패한 시도도 보존합니다.

## 우위 주장보다 먼저 비교

새로운 A/B 성과나 비용 우위를 주장하지 않습니다. 이 작업들을 비교 실험에 사용할 때는 작업, 시작 저장소, 후보 버전, 완료 검사, 권한, 모델, 예산을 실행 전에 고정합니다.

1. 기본 에이전트에 작업과 동일한 완료 기준을 제공합니다.
2. 같은 에이전트에 간결하고 작업에 맞는 프로젝트 지침을 추가합니다.
3. 같은 에이전트에 NULNUL을 적용하고, 설정과 기능 선택 비용도 포함합니다.

실행 순서를 교차 배치하고 시작 상태를 분리합니다. 생성된 해법과 독립적으로 미리 정한 검사로 결과를 평가하며, 반드시 실패해야 하는 잘못된 입력이나 구현도 포함합니다. 실패한 시도, 재시도, 경과 시간, 토큰 또는 금전 비용을 모두 기록합니다. 검증된 결과 품질을 먼저 비교하고 실질적으로 동등한 결과 사이에서 비용을 비교합니다. 별도 하네스 설정이 필요 없는 작은 작업도 사례에 포함해야 합니다.

이는 평가 규칙 제안이지 실행한 실험이 아닙니다. 이미 공개되어 노출된 이 예제로 개인 적응이나 프로젝트 간 일반화 성능을 주장하지 않습니다. 그러한 주장은 저장소의 별도 전이·홀드아웃 게이트를 충족해야 합니다.

## 공개 범위

사례집을 읽거나 로컬 예제를 실행하는 데 계정 생성, 플러그인 설치, 유료 런타임, 외부 업로드, 배포는 필요하지 않습니다. 합성 데이터만 사용하세요. 예약 서버는 루프백에서만 열리며 공개 호스팅용이 아닙니다. 새로운 외부 연동이나 실제 모델 실험에는 별도 명시적 승인과 범위를 제한한 실행 계획이 필요합니다.
