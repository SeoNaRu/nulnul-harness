# Local source evidence

The HyperAgents paper describes a task agent and a meta agent in one editable program. The meta agent can modify both the task agent and the procedure that generates future modifications. Meta-level improvements such as persistent memory and performance tracking accumulated across runs and transferred across domains.

Source: https://arxiv.org/abs/2603.19461

Claude Managed Agents is a hosted runtime for sessions, sandboxing, credentials, and tracing. It is not the HyperAgents self-referential improvement framework and is not required for this local project.

Source: https://news.hada.io/topic?id=28326
