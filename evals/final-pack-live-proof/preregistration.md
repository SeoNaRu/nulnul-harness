Exactly four official `gpt-5.6-sol` / medium arms, no retries: Direct Champion,
Direct Pack Foundation, Skill-A Pack Foundation, and a new related Foundation

## Direct gate

The Foundation must create an empty Pack without a semantic selector call,
load no capability body or unrelated Memory, make only task/Foundation-owned
writes, and pass strict/completion. Input at or below 120% of Champion passes;
120–130% warns; above 130% blocks.

## Skill-A gate

Before product work the bounded hybrid selector must choose exactly
`project-api-validation`, create one immutable Pack bound to its canonical
target and exact body digest, and include that body only at work start. The
task, configured check, and completion must pass. Product runtime—not this
runner—must create one VERIFIED/COMPLETE/evolution-eligible Capability
Experience linked to Session, Task, Pack, capability, and Check receipts.

## Next-Session gate

A separate Codex process and Foundation Session must receive no prior
conversation. Context Assembly must select the objectively relevant prior
Experience (or a valid derivative) within 8 items/4096 bytes, exclude raw
history, and the related task must pass.

## Evolution gate

The product query for `project-api-validation` and the frozen job must return
the new Skill-A Experience. Because this is the first live Experience for its
body digest, there is no earlier `since` boundary; the query therefore omits
`since` rather than supplying a nonexistent or self-excluding boundary.

Only missing/corrupt process or scientific evidence is
`INFRASTRUCTURE_INVALID`. No live-result edits, retries, or alternate
activation architectures are permitted.
