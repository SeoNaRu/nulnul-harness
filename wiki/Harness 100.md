# Harness 100

## 정의

`nulnul-harness`의 릴리스 행동과 안전 경계를 100점으로 확인하는 공개 게이트다. 제품 품질 향상률이나 다른 하네스와의 상대 성능 점수가 아니다.

```bash
python3 scripts/harness_100.py
```

## 판정 원칙

- `passed`로 기록된 격리 실행만 점수를 얻는다.
- 배점 합계가 정확히 100이 아니면 계산기가 실패한다.
- 한 시나리오라도 재실행이 필요하면 100점을 표시하지 않는다.
- 상세 프롬프트와 기대 행동은 `evals/cases.json`, 실행 근거는 `evals/results.json`이 기준이다.

## 한계

이 게이트는 트리거, 작업 지속, 재사용, 권한, 비밀, 전역 변경과 진화 규칙을 검증한다. 실제 작업 품질·비용·시간 향상은 별도의 반복 A/B 실험으로 판단한다.
