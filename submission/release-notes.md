# nulnul harness 1.6.0

This release adds one-generation bounded evolution episodes. A Coach may propose a small candidate set from a reproduced failure, but fixed budgets, archive deduplication, permission and HOLDOUT boundaries, deterministic evaluation, and an independent Gate own the decision. `NO_PROMOTION` remains a valid result.

The retrospective episode deduplicated a rejected mechanism and selected an already verified winner. A later live episode started from a new public-positioning failure: two unchanged champion checks each found seven violations, while one newly generated metadata candidate reduced the result to zero and stopped on `SUCCESS` within two model invocations. The claim is limited to that activation-metadata failure family; it is not open-ended, personal, cross-project, or harness-wide autonomous improvement.

The plugin remains skills-only with no server, daemon, recursive Coach, background loop, raw transcript store, new permission, or reused HOLDOUT. All 112 repository tests and the final 100/100 Release Gate pass. A fresh GitHub-marketplace-installed 1.6.0 adoption preserved two existing agent profiles, made zero protected writes, produced verified resumable state, and passed five executable checks; no 1.5.0 evidence was relabeled.
