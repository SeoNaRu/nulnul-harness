# nulnul harness 1.6.0

This release candidate adds one-generation bounded evolution episodes. A Coach may propose a small candidate set from a reproduced failure, but fixed budgets, archive deduplication, permission and HOLDOUT boundaries, deterministic evaluation, and an independent Gate own the decision. `NO_PROMOTION` remains a valid result.

The retrospective episode deduplicated a rejected mechanism and selected an already verified winner. A later live episode started from a new public-positioning failure: two unchanged champion checks each found seven violations, while one newly generated metadata candidate reduced the result to zero and stopped on `SUCCESS` within two model invocations. The claim is limited to that activation-metadata failure family; it is not open-ended, personal, cross-project, or harness-wide autonomous improvement.

The plugin remains skills-only with no server, daemon, recursive Coach, background loop, raw transcript store, new permission, or reused HOLDOUT. Local tests and behavior gates pass; exact-version GitHub-marketplace adoption evidence still requires publication of this candidate.
