# Project Harness 1.0.0

Initial skills-only release. Project Harness inspects a repository, asks only for material unknown decisions, creates the smallest useful project-local agent setup when needed, continues the user's original work, and evolves the setup from bounded evidence. It bundles no MCP server, external service, authentication, telemetry, or UI.

The final package passed local structure validation and eight forward scenarios: five positive workflows and three negative safety or non-trigger cases. No test credentials are required.
